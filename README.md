## 🌟 Core Breakthroughs

This project resolves and replaces the foundational flaws of early transhumanism—specifically dogmatic unfalsifiability, compulsive biological body disposal, and the extinction of individuality through totalitarian homogenization (the Borg dilemma).

### 1. Federated Qualia Preservation (Anti-Homogenization)
- **Rejection of the Borg Soup**: Strictly rejects melting individual minds into a single hive consciousness.
- **Dynamic Interference Waves**: Because each node preserves its unique subjective qualia (first-person phenomenal perspective), phase differences between nodes generate perpetual cognitive interference waves, permanently staving off the thermodynamic heat death (ennui/boredom) of total omniscience.

### 2. Self-Negating AI Bedrock v0.1 (Algorithmic Karl Popper)
- **Engineering Critical Rationalism**: Solves the 2,000-year-old political philosophy dilemma (*"Quis custodiet ipsos custodes?"* / Who guards the guardians?) by embedding hierarchical **Level 0–4 Self-Negation** directly into the governance OS.
- **Axiomatic Postulate**: Enforces `Convergence ≠ Truth` and affirms `Reject (Socratic Ignorance)` as a normal, healthy cognitive state, preventing the governing AI from locking into catastrophic ideological dogmas.

### 3. Pragmatic Embodiment & Cosmic Phase Transition
- **No Compulsive Flesh Rejection**: In planetary and orbital domains, organic bodies, intimacy, tactile presence, and biological affection are preserved and cherished.
- **Thermodynamic Transition at Kardashev IV**: Transitioning into higher-dimensional substrate-independent information structures occurs voluntarily only when expanding into deep intergalactic space, grounded strictly in relativistic physics and dissipative thermodynamics (Dyson / Prigogine).

### 4. Linguistic & Semiotic Qualia Mapping
- **Linguistic Safeguards of Agency**: Grounded in Austin's Speech Act Theory, Saussure's structural differentiation, Wittgenstein's Language-Games, and Lakoff's Cognitive Metaphors.
- **Voluntary Participation**: Proves that *voluntary* engagement creates illocutionary force and semiotic contrast, allowing qualia to be actively reconstructed as cosmic poetic metaphors even after substrate transition.

## 📦 Quick Start

### Prerequisites
- Node.js 20+
- npm or pnpm

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/federated-qualia-manifesto.git
cd federated-qualia-manifesto
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure environment variables (Optional: for AI Console)
```bash
cp .env.example .env
```
Add your Google AI Studio API key in `.env`:
```env
GEMINI_API_KEY="your-gemini-api-key-here"
```
*(Note: All interactive simulations, charts, and philosophical readers work completely offline without an API key).*

### 4. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Production build
```bash
npm run build
npm start
```
