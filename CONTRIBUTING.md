# Contributing to Federated Qualia Manifesto

Thank you for your interest in contributing to the **Federated Qualia Manifesto & Simulation Platform**! We welcome contributions spanning philosophical critique, AI safety alignment, cognitive architecture, thermodynamic modeling, and UI enhancements.

---

## 🧭 Philosophical & Ethical Code of Conduct

1. **Commitment to Critical Rationalism (Popperian Openness)**
   - All models, proposals, and code must remain open to refutation, critique, and self-negation. We categorically reject dogmatism, unfalsifiable claims, and totalitarian homogenization.
2. **Preservation of Subjective Qualia**
   - Contributions must respect the sanctity of individual perspective, human dignity, and voluntary agency. We do not accept implementations that simulate coercive assimilation or eradication of subjective consciousness.
3. **Existential Risk Neutralization**
   - Safety guardrails (prevention of nuclear, biological, or autonomous self-destruction) take absolute engineering precedence over unconstrained capability acceleration.

---

## 🛠 Development Workflow

### 1. Issues & Discussions
- Before submitting major philosophical restructuring or architectural changes, please open an Issue to discuss your thesis with the community.

### 2. Code Standards
- **TypeScript**: Strict type-checking enabled. Standard clean patterns.
- **Styling**: Tailwind CSS utility classes. Maintain the dark editorial cyberpunk aesthetic.
- **Linting & Build**: Always verify before submitting a Pull Request:
  ```bash
  npm run lint
  npm run build
  ```

### 3. Pull Request Guidelines
- Provide a clear description of the philosophical or computational improvement.
- Ensure the applet builds without errors or regressions.

Thank you for helping pioneer an open, self-critical, and qualia-preserving future for intelligence!
